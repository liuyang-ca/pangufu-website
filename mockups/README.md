# PANGUFU homepage concepts

Both previews introduce PANGUFU SOLUTION LTD. as an independent software company, use the same company description and support contact, and end with the legal company name and current-year copyright.

- [Studio — dark](studio.html): near-black canvas, charcoal lines, lime accent, a left-aligned introduction and an original CSS geometric mark.
- [Quiet — light](quiet.html): soft off-white canvas, calm green detail, a centered introduction and a spare orbit motif.

**Recommendation: Quiet.** Its generous spacing and restrained palette make the company introduction feel welcoming and direct. Studio suits a more contemporary software-workshop feel.

Open [the comparison index](index.html), then choose a preview. Both pages have a working Support anchor and selectable `support@pangufu.ca` mailto link. For local HTTP preview, run `python3 -m http.server 8000` from the repository root and open `http://localhost:8000/mockups/`.

These are company-only concepts. Their illustrations are CSS decoration; there are no product screenshots, app availability claims, or app-specific links.

Desktop and mobile viewport captures and full-page captures are saved in `../output/playwright/`.
